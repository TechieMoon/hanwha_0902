# 가상환경 코드

## 파이썬 버전 확인하기

VSCode에서 command prompt 키는 법: ``ctrl + ` ``

```cmd
python --version
```

출력 예시

```cmd
Python 3.12.10
```

## 가상환경 만들기

```cmd
python -m venv .firstvenv
```

## 가상환경 실행

```cmd
.firstvenv\Scripts\activate.bat
```

가상환경이 생성된 폴더의 Scripts\activate.bat의 상대 경로를 복사한 뒤 cmd에서 실행

출력 예시

```cmd
(.firstvenv) C:\Users\start\Documents\GitHub\hanwha_0902>   
```

## 가상환경 종료

```cmd
.firstvenv\Scripts\deactivate.bat
```

# Python 설치

> **한눈에 보기**
> - 파이썬은 **3.12.x** 버전으로 설치했다. (수업 환경: 3.12.10)
> - 버전이 다르면 라이브러리끼리 충돌할 수 있어서, 수업 전체에서 같은 버전을 쓴다.
> - 설치 후 `python --version`으로 확인한다.

## 왜 버전을 맞추나

파이썬 버전에 따라서 라이브러리 간의 충돌이 일어날 수 있으므로 3.12.x 버전으로 설치했다. 새로 나온 버전(3.13, 3.14 등)은 아직 일부 라이브러리가 지원하지 않거나 설치가 안 되는 경우가 있어서, 수업에서는 검증된 한 버전으로 통일한다.

## 설치할 때 확인할 것

- 설치 첫 화면에서 **"Add python.exe to PATH"**에 체크해야 터미널 어디서든 `python` 명령이 동작한다.
- 설치가 끝나면 새 터미널을 열어 확인한다.

```cmd
python --version
```

```txt
Python 3.12.10
```

- 컴퓨터에 파이썬이 여러 개 깔려 있으면 VS Code 오른쪽 아래(또는 `Ctrl+Shift+P` → "Python: Select Interpreter")에서 어떤 파이썬을 쓸지 고른다.

</details>

설치할 때 PATH에 추가하지 않았거나, 설치 후 터미널을 새로 열지 않은 경우다.
</details>

# 깃허브 데스크탑

![Github Desktop UI](https://github.com/TechieMoon/hanwha_0902/blob/main/ex0904/github_desktop_ui.png)

1. 레포지토리의 파일들을 수정하면 github desktop의 UI에서 Changes 리스트에 반영된다
2. 깃허브에 반영하고 싶은 변경 내용을 체크하고 commit한다. 제목과 내용은 원하는 걸로 작성한다.
3. `Push origin` 버튼을 클릭하면 깃허브 서버에 반영된다.

# 주의사항

1. 서로 다른 컴퓨터에서 같은 파일의 같은 항목을 수정하면 나중에 push한 사람이 충돌이 일어날 수 있으므로 항상 pull을 미리 해보는 것을 추천

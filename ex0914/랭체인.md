# 랭체인 사용법

다음과 같이 임포트 해야함

```python
from langchain_openai import ChatOpenAI
```

그 전에 패키지 설치해야 함

```cmd
pip install langchain_openai
```

다음과 같이 코드를 작성하면 ChatGPT의 답변을 얻을 수 있다.

```python 
llm = ChatOpenAI(
    temperature=0.1,
    model="gpt-4o-mini"
)

question = "미국의 수도는 어딜까요?"

response = llm.invoke(question)

print(response.content)
```

# 폼 데이터, lifespan, 파일 업로드

HTML 폼이 보내는 데이터를 받는 방법, 서버가 켜지고 꺼질 때 코드를 실행하는 **lifespan**, 그리고 파일을 업로드받아 서버에 저장하는 방법을 실습했다. 파일 저장 예제에서는 업로드 파일 이름을 그대로 경로에 쓰면 생기는 보안 문제를 직접 확인하고 고쳤다.

- 코드: [`exam15.py`](exam15.py), [`exam15_1.py`](exam15_1.py), [`exam15_2.py`](exam15_2.py), [`exam16.py`](exam16.py), [`exam17.py`](exam17.py), [`exam18.py`](exam18.py)
- 강의 교안(PDF)은 강사님 자료라 저장소에는 넣지 않고, 내용을 5절에 요약했다.
- 폼과 파일을 받으려면 `python-multipart` 패키지가 필요하다.

## 1. 폼 데이터 (exam15)

```python
@app.post("/insert")
async def login(username: Annotated[str, Form()], emailaddress: Annotated[str, Form()]):
    return {"username": username, "emailaddress": emailaddress}
```

HTML 폼(`method="post"`)은 JSON이 아니라 `키=값&키=값` 형식(`application/x-www-form-urlencoded`)으로 보낸다. 그래서 pydantic 모델이 아니라 `Form()`으로 받는다.

- `username=dooly`, `emailaddress=a@b.c` → `{"username":"dooly","emailaddress":"a@b.c"}`
- `emailaddress`를 빠뜨리면 422 `missing`
- 폼의 action이 `/insert/`(끝에 `/`)라서 307 리다이렉트로 `/insert`에 다시 보내졌다. 307은 POST 방식과 본문을 그대로 유지해서 결과는 정상이었다.

## 2. lifespan: 서버 시작과 종료 (exam15_1)

```python
@asynccontextmanager
async def startup(app: FastAPI):
    print("UVICORN에 의해 서버가 기동될 때 실행됩니다요~~~")
    friends.extend(["둘리", "또치", "도우너", "희동이", "마이콜"])
    yield
    print("UVICORN이 종료될 때 실행됩니다요~~~")

app = FastAPI(lifespan=startup)
```

`yield` 앞은 서버가 켜질 때, 뒤는 꺼질 때 한 번씩 실행된다. 실행해 보니 시작 메시지 → `/myfriend` 응답(`{"myfriend":"희동이"}`, 무작위) → 종료 메시지 순서로 출력됐다. 모델 불러오기나 DB 연결처럼 요청마다 하면 느린 준비 작업을 여기서 한 번만 한다.

`exam15_1`, `exam15_2`는 맨 위의 `app = FastAPI()`를 아래에서 `FastAPI(lifespan=startup)`로 다시 만들어서, 첫 줄은 쓰이지 않는다.

## 3. 파일 업로드 (exam16, exam17)

| 방식 | 코드 | 결과 | 특징 |
|---|---|---|---|
| 바이트로 받기 | `file: bytes = File()` | 11바이트 파일 → `{"file_size":11}` | 내용 전체를 메모리에 올림. 작은 파일용 |
| UploadFile | `file: UploadFile` | `{"filename":"a.txt"}` | 파일 이름·형식 정보 포함, 큰 파일은 디스크 임시 파일 사용 |
| 여러 개 (바이트) | `files: list[bytes] = File()` | 5바이트, 3바이트 → `{"file_sizes":[5,3]}` | |
| 여러 개 (UploadFile) | `files: list[UploadFile]` | `{"filenames":["a.txt","b.txt"]}` | |

HTML 폼은 `enctype="multipart/form-data"`여야 파일이 전송되고, `<input type="file" multiple>`로 여러 파일을 고를 수 있다.

## 4. 업로드 파일 저장과 경로 조작 문제 (exam18)

```python
@asynccontextmanager
async def my_lifespan(app: FastAPI):
    if not os.path.isdir("static/files"):
        os.mkdir("static/files")      # 서버가 켜질 때 저장 폴더 준비
    yield

@app.post("/singleuploadfile")
async def create_upload_file(file: UploadFile):
    path = f"static/files/{file.filename}"     # 원래 코드
    content = await file.read()
    with open(path, 'w+b') as fp:
        fp.write(content)
```

`memo.txt`를 올리면 `{"file":"memo.txt","content":"text/plain","path":"static/files/memo.txt"}`로 저장된다.

**확인한 문제:** `file.filename`은 클라이언트가 보내는 값이다. 브라우저는 파일 이름만 보내지만, 프로그램으로 요청하면 이름을 마음대로 정할 수 있다. 파일 이름을 `../evil.txt`로 보내 봤더니 응답의 경로가 `static/files/../evil.txt`였고, 실제로 `static/files` **밖**인 `static/evil.txt`가 만들어졌다. 이름을 `../../exam18.py`처럼 보내면 서버 코드 파일까지 덮어쓸 수 있는 **경로 조작(path traversal)** 취약점이다.

**고친 방법:** `os.path.basename(file.filename)`으로 경로를 떼고 파일 이름 부분만 쓰도록 단일·다중 업로드 둘 다 바꿨다. 다시 같은 요청을 보내니 `static/files/evil.txt`에 저장되고 `static/evil.txt`는 생기지 않았다.

그 밖에:

- 같은 이름의 파일을 올리면 기존 파일을 덮어쓴다. 실제 서비스에서는 이름에 시간이나 UUID를 붙여 겹치지 않게 한다.
- `os.mkdir("static/files")`는 상위 폴더 `static`이 없으면 실패한다. `os.makedirs("static/files", exist_ok=True)`를 쓰면 한 번에 만들어진다.
- 업로드 파일을 `static` 아래에 저장하면 `/static/files/파일이름`으로 누구나 내려받을 수 있다(정적 파일을 연결했을 경우). 공개해도 되는 파일만 이렇게 저장한다.

## 5. 강의 교안 정리: UploadFile, lifespan, CORS

**UploadFile이 bytes보다 나은 점**

- **스풀 파일**을 쓴다. 정해진 크기까지만 메모리에 두고 넘으면 디스크에 저장해서, 이미지·동영상 같은 큰 파일도 메모리를 많이 쓰지 않는다.
- 메타데이터를 준다: `filename`(파일 이름), `content_type`(MIME 형식, 예: `image/jpeg`), `file`(실제 파일 객체, 다른 라이브러리에 바로 넘길 수 있음).
- `await file.read()`, `await file.write(data)`, `await file.close()` 같은 비동기 메서드가 있다.

**lifespan 기본 형태**: 교안은 `yield`를 `try/finally`로 감싸는 형태를 보여 준다. 이렇게 하면 서버가 오류로 끝나도 `finally`의 정리 코드(DB 연결 닫기 등)가 실행된다.

```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    # 시작할 때 할 일
    try:
        yield
    finally:
        # 종료할 때 할 일
        ...

app = FastAPI(lifespan=lifespan)
```

**CORS 설정** (교안에만 있고 실습 코드에는 없음): 브라우저는 보안 때문에 다른 출처(주소·포트가 다른 곳)에서 불러온 페이지가 내 API를 자바스크립트로 호출하는 것을 기본으로 막는다. 예를 들어 VS Code Live Server(`http://127.0.0.1:5500`)로 연 HTML이 FastAPI(`http://127.0.0.1:8000`)를 AJAX로 부르면 막힌다. 서버에서 허용할 출처를 등록하면 된다.

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://127.0.0.1:5500", "http://127.0.0.1:5501"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

이번 실습의 AJAX 예제(exam9_1, exam15_2)는 HTML과 API를 같은 FastAPI 서버가 주기 때문에 CORS 설정이 필요 없었다.

## 정리

| 기능 | 코드 | 필요한 것 |
|---|---|---|
| 폼 값 받기 | `Annotated[str, Form()]` | `python-multipart` |
| 시작·종료 시 실행 | `@asynccontextmanager` + `FastAPI(lifespan=...)` | `yield` 앞뒤로 나눔 |
| 파일 받기 | `bytes = File()` / `UploadFile` | `enctype="multipart/form-data"` |
| 여러 파일 | `list[bytes] = File()` / `list[UploadFile]` | `<input type="file" multiple>` |
| 저장 | `await file.read()` → `open(path, "wb")` | 파일 이름은 `os.path.basename()`으로 경로 제거 |

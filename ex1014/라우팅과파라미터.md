# FastAPI 시작하기: 라우팅과 경로·쿼리 파라미터

FastAPI는 파이썬 타입 힌트를 이용해 웹 API를 만드는 프레임워크다. 함수에 데코레이터(`@app.get("/주소")`)를 붙이면 그 주소의 요청을 처리하는 **엔드포인트**가 되고, 함수 인자에 적은 타입대로 요청 값을 **변환하고 검사**해 준다. 앞으로 LLM 에이전트를 웹 서비스로 만들 때 쓰게 될 기본기다.

- 코드: [`exam1.py`](exam1.py) ~ [`exam6.py`](exam6.py)
- 실행: 이 폴더에서 `uvicorn exam1:app --reload` → 브라우저에서 `http://127.0.0.1:8000`, 자동 문서는 `http://127.0.0.1:8000/docs`
- 수업 환경: Python 3.12, fastapi 0.143.0, starlette 1.7.0, pydantic 2.14.1, uvicorn 0.54.0
- 아래 결과는 같은 버전에서 FastAPI의 `TestClient`로 각 주소를 직접 호출해서 확인한 것이다.

## 1. 첫 엔드포인트와 응답 형식 (exam1, exam2)

```python
app = FastAPI()

@app.get("/")
async def root():
    return {"message": "안녕? FastAPI!! ^^"}
```

| 주소 | 돌려준 값 | 응답 |
|---|---|---|
| `/test1` | `{"name": "둘리"}` | JSON 객체 |
| `/test2` | `["둘리", "또치", "도우너"]` | JSON 배열 |
| `/test3` | `"<h1>안녕?</h1>"` | JSON **문자열** `"<h1>안녕?</h1>"` (`application/json`) |
| `/test4` | `1000` | JSON 숫자 |

무엇을 돌려주든 기본은 JSON 응답이다. `/test3`은 HTML처럼 보이지만 브라우저에는 따옴표가 붙은 글자로 나온다. HTML 페이지로 보여 주려면 `HTMLResponse`나 템플릿을 써야 한다([템플릿과AJAX.md](템플릿과AJAX.md)).

## 2. 경로 파라미터 (exam3, exam4)

URL 경로의 `{이름}` 부분이 같은 이름의 함수 인자로 들어온다.

```python
@app.get("/items/{item_id}")
def read_item(item_id):                       # 타입 없음 -> str
    return {"item_id": item_id}

@app.get("/friend/{name}/{age}")
async def read_item(name: str, age: int):     # 타입 있음 -> 변환 + 검사
    return {"이름": name, "나이": age}
```

| 요청 | 결과 |
|---|---|
| `/items/3` | `{"item_id":"3"}` (타입을 안 적어서 문자열) |
| `/friend/둘리/10` | `{"이름":"둘리","나이":10}` (숫자로 변환) |
| `/friend/둘리/열살` | **422** `int_parsing`: "Input should be a valid integer" |

타입 힌트가 곧 검증 규칙이다. 잘못된 값이 오면 함수가 실행되기도 전에 FastAPI가 422 오류와 이유를 돌려준다.

**Enum으로 값 제한하기 (exam4):** `class ModelName(str, Enum)`으로 `alexnet`, `resnet`, `lenet`만 허용했다. `/models/vgg`는 422 "Input should be 'alexnet', 'resnet' or 'lenet'"이 나왔고, `/docs`에서는 선택지가 드롭다운으로 표시된다.

**경로 전체 받기:** `{file_path:path}`는 `/`가 들어간 경로를 통째로 받는다. `/files//home/user/a.txt` → `{"file_path":"/home/user/a.txt"}`

## 3. 쿼리 파라미터 (exam5, exam6)

경로에 없는 함수 인자는 URL의 `?` 뒤에서 받는다.

```python
@app.get("/items")
async def read_item(skip: int = 0, limit: int = 10):          # 기본값 있음 -> 생략 가능
    return fake_items_db[skip : skip + limit]

@app.get("/items/{item_id}")
async def read_item(item_id: str, q: str | None = None):      # None 기본값 -> 선택
    ...

@app.get("/items2/{item_id}")
async def read_user_item(item_id: str, needy: str):           # 기본값 없음 -> 필수
    ...
```

| 요청 | 결과 |
|---|---|
| `/items?skip=1&limit=2` | `[{"item_name":"Ddochi"},{"item_name":"Dauner"}]` |
| `/items/foo?q=bar` | `{"item_id":"foo","q":"bar"}` |
| `/items/foo?q=hi&short=true` | `{"item_id":"foo","q":"hi"}` (short가 참이라 description 생략) |
| `/items/foo?short=yes` | `{"item_id":"foo"}` (`yes`도 참으로 해석) |
| `/items/foo?short=abc` | **422** `bool_parsing` |
| `/items2/foo` | **422** `missing`: needy가 필수 |

`bool` 파라미터는 `true/false` 외에 `1/0`, `yes/no`, `on/off`도 받는다.

## 4. 정적 파일 (exam6)

```python
app.mount("/static", StaticFiles(directory="static"), name="static")
```

`static` 폴더를 `/static` 주소에 연결한다. `static/images/1.jpg`는 `/static/images/1.jpg`로 열린다. 실행한 위치에 `static` 폴더가 있어야 한다.

> 수업에서 쓴 `static/images`의 이미지와 동영상은 강사님 자료(캐릭터 이미지 등)라 저장소에 넣지 않았다. 템플릿 예제를 실행하면 이미지는 깨져 보인다. `static` 폴더 자체가 없으면 `StaticFiles`가 서버 시작 단계에서 오류를 내므로, exam8 템플릿이 쓰는 `static/css/styles.css`만 넣어 두었다.

## 정리

| 받는 곳 | 코드 | 예 |
|---|---|---|
| 경로 | `@app.get("/items/{item_id}")` + `item_id: int` | `/items/3` |
| 경로 전체 | `{file_path:path}` | `/files//home/a.txt` |
| 쿼리 (선택) | `q: str \| None = None`, `skip: int = 0` | `/items?skip=1` |
| 쿼리 (필수) | `needy: str` (기본값 없음) | `/items2/foo?needy=x` |
| 값 제한 | `Enum` | `/models/alexnet` |
| 정적 파일 | `app.mount("/static", StaticFiles(...))` | `/static/images/1.jpg` |

타입이 맞지 않거나 필수 값이 빠지면 모두 **422**와 함께 어떤 값이 왜 틀렸는지(`loc`, `msg`, `input`)가 JSON으로 온다.

3. 에러 발생

![conflict](https://github.com/TechieMoon/hanwha_0902/blob/main/ex0907/conflict.png)

에러가 발생한 이유는 이미 다른 컴퓨터에서 수정 한 파일을 pull해서 이어서 수정하지 않고 예전 commit 버전에서 수정함이다.

4. 에러 해결

```markdown
<<<<<<< HEAD
3
=======
2
>>>>>>> 930824ae26801605cd5864a36519d5f230f5affd
```

충돌이 나면 위와 같이 충돌이 일어난 문장들은 저렇게 텍스트로 표시되어 있다.

직접 수정 후 다시 push하면 된다.

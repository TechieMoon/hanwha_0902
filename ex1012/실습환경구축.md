# 실습 환경 구축 (10월 12일)

10월 12일부터 강사님 자료로 수업이 바뀌면서, 강사님이 나눠 준 「실습환경구축」 안내 문서대로 윈도우 PC에 실습 환경을 새로 만들었다. 안내 문서는 강사님 자료이고 수업용 API 키가 들어 있어서 저장소에 올리지 않고, 진행한 순서만 정리했다.

## 1. API 키 준비와 등록

| 키 | 용도 | 발급 |
|---|---|---|
| OpenAI API Key | GPT 모델, 이미지 생성, 임베딩 | 유료. 수업용 키를 제공받음 |
| Gemini API Key | Gemini 모델 | Google AI Studio → 로그인 → Get API Key → Create API Key. 신용카드를 등록하지 않은 무료 등급(하루 요청 수 제한은 있지만 수업에는 충분) |

키는 코드에 쓰지 않고 윈도우 **사용자 환경변수**로 등록했다. `setx`는 새로 연 터미널부터 적용된다.

```bat
setx OPENAI_API_KEY "sk-..."
setx GEMINI_API_KEY "..."
```

`OpenAI()`는 환경변수 `OPENAI_API_KEY`를 자동으로 읽고, Gemini는 `os.environ.get("GEMINI_API_KEY")`로 읽어서 넘기거나, `google-genai`의 `genai.Client()`가 환경변수에서 자동으로 읽는다. 그래서 노트북에는 키가 남지 않는다. (단, `print(os.environ.get(...))`처럼 키를 출력하면 실행 결과에 키가 저장되므로, [`exam1.ipynb`](exam1.ipynb)에서는 앞부분만 출력하도록 바꿔 두었다.)

## 2. 프로그램 설치

1. **Python** 설치 (requirements 파일이 Python 3.13 기준)
2. **Ollama** 설치 후 로컬 모델 내려받기
   ```bat
   ollama pull llama3.1
   ollama pull exaone3.5
   ```
3. **Docker Desktop** 설치 (requirements에 PostgreSQL·pgvector 패키지가 있어서 이후 벡터 DB 실습에 쓰일 것으로 보임)
4. **Visual Studio Code** 설치 (주피터 노트북은 VS Code에서 실행)

## 3. 가상환경과 패키지

소스 폴더 `C:\education_llm`을 만들고 명령 프롬프트에서 실행했다.

```bat
cd \education_llm
python --version

python -m venv eduvenv
eduvenv\Scripts\activate
python -m pip install --upgrade pip
pip install --upgrade --no-cache-dir -r requirements.txt

:: VS Code / 주피터에서 이 가상환경을 커널로 고를 수 있게 등록
python -m ipykernel install --user --name=eduvenv --display-name "Python (eduvenv)"
dir %APPDATA%\jupyter\kernels
```

`requirements.txt`에 들어 있는 패키지를 용도별로 보면:

| 분류 | 패키지 |
|---|---|
| LLM 연동 | `openai`, `google-genai`, `ollama`, `python-dotenv`, `tiktoken` |
| 웹 프레임워크 | `fastapi`, `uvicorn[standard]`, `streamlit`, `httpx` |
| RAG / 벡터 DB | `psycopg2-binary`, `pgvector`, `psycopg[binary]` |
| MCP | `mcp` |
| 노트북 | `jupyter`, `ipykernel`, `nbformat` |
| 테스트·유틸 | `pytest`, `pytest-asyncio`, `pydantic`, `pytz` |

수업 중에 필요한 패키지는 노트북에서 `%pip install`로 추가했다(10/13 `lxml`, `selenium`).

## 정리

- 키는 **환경변수**에, 코드는 `os.environ`으로 읽는다. 키를 출력하는 셀은 저장 전에 지우거나 가린다.
- 프로젝트마다 **가상환경**(`venv`)을 만들고, `ipykernel`로 등록해야 노트북에서 그 환경을 커널로 고를 수 있다.
- 로컬 모델(Ollama), 클라우드 모델(OpenAI, Gemini)을 모두 쓸 수 있게 준비했다.

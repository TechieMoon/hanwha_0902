# 동적 웹 페이지 수집: Selenium

요즘 웹 페이지는 처음 받은 HTML에 내용이 다 들어 있지 않고, 페이지가 열린 뒤 **자바스크립트가 데이터를 받아 화면을 그리는** 경우가 많다. 이런 **동적 페이지**는 `requests`로 HTML만 받아서는 원하는 내용을 찾을 수 없다. **Selenium(셀레니움)**은 실제 브라우저를 코드로 조작해서 사람이 보는 것과 같은 화면에서 데이터를 꺼낸다. 클릭, 입력, 스크롤까지 할 수 있어서 웹 서비스 자동화 테스트에도 쓰인다.

- 코드: [`dataexam/exam3.ipynb`](dataexam/exam3.ipynb)
- 강의 교안(PDF)은 강사님 자료라 저장소에는 넣지 않고, 내용을 7절에 요약했다.

## 1. 설치와 브라우저 열기

```python
%pip install selenium          # 4.51.0 설치

from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.common.keys import Keys

driver = webdriver.Chrome()    # 크롬 창이 열린다
driver.get('https://www.naver.com/')
driver.quit()                  # 다 쓰면 브라우저 닫기
```

셀레니움 4.6 이후로는 Selenium Manager가 크롬 드라이버를 자동으로 준비해 줘서, 드라이버 파일을 따로 받지 않아도 `webdriver.Chrome()`만으로 브라우저가 열린다.

## 2. 입력하고 검색하기

```python
target = driver.find_element(By.ID, "query")       # 네이버 검색창
target.send_keys('서울 날씨')
target.send_keys(Keys.ENTER)                         # 또는 target.submit()
```

- 같은 검색창을 `By.CSS_SELECTOR, "[name='query']"`, `By.ID, "query"`, `By.CLASS_NAME, "search_input"` 세 가지 방법으로 찾을 수 있었다.
- `input()`으로 받은 검색어를 그대로 넣어 검색하는 것도 해 봤다.

## 3. 클릭, 기다리기, 스크롤, 스크린샷

```python
# 버튼이 클릭 가능해질 때까지 최대 15초 기다렸다가 클릭
wait = WebDriverWait(driver, 15)
btn = wait.until(EC.element_to_be_clickable((By.CSS_SELECTOR, '#shortcutArea ... span.service_icon.type_blog')))
btn.click()

driver.execute_script('window.scrollTo(0, document.body.scrollHeight)')               # 맨 아래로
driver.execute_script("arguments[0].scrollIntoView({block: 'center'});", element)      # 특정 요소로

driver.save_screenshot('output/full_page_screenshot.png')   # 화면 전체
element.screenshot('output/element_screenshot.png')         # 요소 하나
```

- 페이지가 다 그려지기 전에 요소를 찾으면 "요소를 찾을 수 없음" 오류가 난다. `WebDriverWait` + `expected_conditions`로 **조건이 될 때까지 기다리는 것**이 `time.sleep()`으로 정해진 시간만큼 기다리는 것보다 안정적이다.
- `execute_script()`로 페이지 안에서 자바스크립트를 실행할 수 있다. 스크롤처럼 셀레니움 명령이 따로 없는 동작에 쓴다.

실습 코드에서 확인한 점:

- 마우스 클릭 셀의 주석은 "이미지 검색 페이지 버튼"인데 선택자는 `type_blog`, 즉 **블로그** 바로가기였다.
- 스크롤 셀의 주석은 "500 픽셀"인데 코드는 `scrollTo(0, 1000)`이었다.
- 일부 셀은 `By`를 import하지 않고 썼는데, 앞 셀에서 이미 import해서 실행된 것이다. 커널을 새로 시작하고 그 셀만 실행하면 `NameError`가 난다. 노트북 셀은 혼자 실행해도 되도록 import를 넣어 두는 게 좋다.
- 구글 로고를 찾은 선택자 `#sI1XGe`처럼 자동으로 만들어진 id는 사이트가 바뀌면 달라지기 쉽다.

## 4. 정적 수집 vs 동적 수집: 스타벅스 매장 찾기

```python
# urllib으로 받은 HTML에서 매장 목록 찾기
li = BeautifulSoup(urllib.request.urlopen(url).read().decode(), "html.parser").find_all('li', class_="quickResultLstCon")
print(li)        # []

# 셀레니움으로 연 브라우저에서 찾기
driver.get(url)
print(driver.find_element(By.CLASS_NAME, "quickResultLstCon").text)
```

```txt
[]
---
무교로
서울특별시 중구 무교로 15 (무교동)
1522-3232
리저브 매장 2번
```

같은 페이지인데 `urllib`은 **빈 리스트**, 셀레니움은 매장 정보를 찾았다. 매장 목록은 페이지가 열린 뒤 자바스크립트가 그리는 내용이라 처음 받은 HTML에는 없고, 셀레니움은 실제 브라우저가 자바스크립트까지 실행한 화면에서 찾기 때문이다. 정적 수집과 동적 수집이 왜 따로 있는지 보여 주는 실습이었다.

## 5. 요소 찾는 방법

실습 페이지(`exercise_css.html`)에서 같은 요소를 여러 방법으로 찾았다.

| 방법 | 예 | 결과 |
|---|---|---|
| `By.TAG_NAME` | `'h1'` | `CSS 선택자 학습` |
| `By.CLASS_NAME` | `'subtitle'` | `웹 클라이언트 기술` (elements면 2개) |
| `By.ID` | `'btype'` | `HTML5` |
| `By.LINK_TEXT` / `PARTIAL_LINK_TEXT` | `'파이썬 학습 사이트'` / `'사이트'` | 전체 일치 1개 / 부분 일치 2개 |
| `By.CSS_SELECTOR` | `'ul>li.atype'` | `CSS3`, `Ajax` |
| `By.XPATH` | `'//ul/li[@class="atype"]'` | `CSS3`, `Ajax` (CSS 선택자와 같은 결과) |

`find_element()`는 첫 번째 하나, `find_elements()`는 리스트를 돌려준다. 글자는 `.text`, 속성은 `get_attribute('src')`로 꺼낸다.

```python
for page in range(2, 31):

    points.extend([p.text for p in driver.find_elements(By.CLASS_NAME, 'story-point')])

```

30페이지 × 10건 = 300건을 `movie.csv`(평점, 관람 포인트, 리뷰)로 저장했다. 저장된 파일을 확인해 보니:

- 300행 × 3열, 평점 10점이 211건으로 가장 많았다.
- 두 번째 열 이름을 `genre`로 했지만 실제로는 장르가 아니라 **관람 포인트**(`스토리`, `배우`, `연출`, `영상미`)가 들어갔다. 포인트를 여러 개 고른 관람평은 `스토리배우`처럼 구분자 없이 붙어서 저장됐다.
- 리뷰 본문은 큰따옴표를 `""`로 바꾸고 전체를 따옴표로 감싸서 쉼표나 줄바꿈이 있어도 CSV가 깨지지 않았다.

### YES24 도서 리뷰

스크롤해야 리뷰 영역이 불러와져서 `scrollTo`로 2000픽셀씩 내리고, '더보기'는 `execute_script("arguments[0].click();", 요소)`로 눌렀다. 일반 `click()`은 다른 요소에 가려져 있으면 실패할 수 있는데, 자바스크립트 클릭은 화면 상태와 상관없이 클릭 이벤트를 보낸다.

⚠️ 결과 저장에 쓴 `writelines(temp_list)`는 항목 사이에 줄바꿈을 넣지 않는다. 그래서 앞 리뷰의 끝과 다음 리뷰의 시작이 붙어서 저장되고, 나중에 리뷰 단위로 다시 나눌 수 없다. `"\n".join(temp_list)`로 쓰거나 리뷰마다 구분자를 넣어야 한다.

## 7. 강의 교안 정리: 동적 페이지와 Selenium

- **정적 페이지**: 서버가 보낸 HTML 소스에 화면에 보이는 내용이 모두 들어 있다(HTML, CSS로만 만든 페이지).
- **동적 페이지**: 화면에는 보이는데 소스에서는 찾을 수 없는 내용이 있다. 브라우저에서 자바스크립트가 실행되면서 만들거나, Ajax 통신으로 나중에 받아 와서 그린 내용이다.
- **Selenium**은 여러 플랫폼과 언어를 지원하는 브라우저 자동화 도구 모음이고, **WebDriver** API로 설치된 크롬·파이어폭스 같은 브라우저를 직접 띄워 페이지를 열고 조작한다. 브라우저를 직접 쓰기 때문에 자바스크립트가 만든 내용과 Ajax로 늦게 들어오는 내용까지 다룰 수 있다.
- 예전에는 `chromedriver.exe`를 따로 받아 `webdriver.Chrome('드라이버 경로')`로 지정했지만, 최신 Selenium은 드라이버를 알아서 준비해서 `webdriver.Chrome()`만 쓰면 된다.
- **요소 찾기 함수의 두 가지 모양**: 교안에는 `find_element_by_id('btype')` 같은 옛 방식과 `find_element(By.ID, 'btype')` 방식이 같이 나온다. `find_element_by_*` 함수들은 Selenium 4에서 없어져서(이번 실습 버전 4.51.0), 실습 코드처럼 `By`를 쓰는 방식만 동작한다.
- **XPath**: XML 문서 구조를 따라 경로로 요소를 지정하는 W3C 표준 언어다. `//*[@id="f_subtitle"]`(어디든 id가 f_subtitle인 요소), `/html/body/section/article/ul/li[3]`(절대 경로의 세 번째 li)처럼 쓴다.
- 찾은 요소(`WebElement`)에서 `tag_name`, `text`, `get_attribute('속성명')`으로 정보를 꺼낸다. `find_element()`는 하나, `find_elements()`는 리스트를 돌려준다.

## 정리

| | 정적 수집 | 동적 수집 |
|---|---|---|
| 도구 | `requests`, `urllib` + `BeautifulSoup` | `selenium` |
| 방식 | 서버가 보낸 HTML만 받음 | 실제 브라우저가 자바스크립트까지 실행한 화면 |
| 속도 | 빠름 | 느림 (브라우저 실행, 대기 필요) |
| 쓰는 곳 | 내용이 HTML에 바로 있는 페이지 | 자바스크립트로 그리는 페이지, 클릭·입력·스크롤이 필요한 경우 |
| 예 | YES24 검색 결과 | 스타벅스 매장 목록, 메가박스 관람평 페이지 넘기기 |

> 수집한 관람평, 리뷰, 스크린샷은 다른 사람의 글과 사이트 화면이라 저장소에 올리지 않았다.

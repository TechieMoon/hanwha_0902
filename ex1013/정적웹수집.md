# 정적 웹 페이지 수집: urllib, requests, BeautifulSoup

> **한눈에 보기**
> - **크롤링**(HTML 받아오기) + **스크래핑**(필요한 부분 골라내기)
> - 받기: `urllib.request.urlopen` / `requests.get(url, params=...)`
> - 고르기: BeautifulSoup `find`, `find_all`, `select`(CSS 선택자), `get_text(strip=True)`, `tag["href"]`
> - 수집 결과는 남의 자료라 저장소에 올리지 않았다

웹 데이터 수집은 두 단계로 나뉜다. **크롤링**은 웹 페이지의 HTML을 받아오는 것, **스크래핑**은 받은 HTML에서 필요한 부분만 골라내는 것이다. 이번 시간에는 서버가 처음부터 완성된 HTML을 보내 주는 **정적 페이지**를 대상으로, `urllib`과 `requests`로 크롤링하고 `BeautifulSoup`으로 스크래핑했다. 마지막에는 YES24에서 파이썬 책 240권의 제목과 링크를 모으고, 같은 작업을 Gemini와 ChatGPT에게 시켜 결과를 비교했다.

- 코드: [`dataexam/exam1.ipynb`](dataexam/exam1.ipynb)
- 강의 교안(PDF)은 강사님 자료라 저장소에는 넣지 않고, 내용을 6절에 요약했다.

## 1. urllib으로 요청하기

```python
import urllib.request
res = urllib.request.urlopen("http://unico2013.dothome.co.kr/crawling/get.php")
print(res.status)                    # 200
print(res.read())                    # b'<!DOCTYPE html>...\xec\x9d\xb4...'  (바이트)
print(res.read().decode('utf-8'))    # 한글이 정상으로 보인다 (새로 요청한 경우)
```

- `read()`는 **바이트**를 돌려준다. `decode('utf-8')`을 하지 않으면 한글이 `\xec\x9d\xb4...`처럼 보인다. 어떤 인코딩인지는 응답 헤더 `Content-Type: text/html; charset=UTF-8`에 나와 있다.
- URL에는 한글과 공백을 그대로 넣을 수 없어서 인코딩한다. `urlencode({'name': '유니코', 'age': 10})` → `name=%EC%9C%A0%EB%8B%88%EC%BD%94&age=10`. 공백은 `+`가 된다.

### GET과 POST

| 방식 | 파라미터 위치 | urllib 코드 | 서버 응답 |
|---|---|---|---|
| GET | URL 뒤 `?name=...&age=10` | `urlopen(url + "?" + params)` | GET : 이름은 유니코이고 나이는 10이네요!! |
| POST | 요청 본문(body) | `urlopen(url, data=params.encode('ascii'))` | POST : 이름은 유니코이고 나이는 10이네요!! |

POST로 보낼 데이터는 문자열이 아니라 **바이트**여야 해서 `encode()`가 필요하다. 파라미터 없이 GET으로 요청하면 서버가 "이름과 나이를 전달해 주세요!!"라고 답한다.

## 2. requests로 요청하기

`requests`는 `urllib`보다 훨씬 간단하다.

```python
r = requests.get(url, params={'key1': 'value1', 'key2': ['value2', 'value3']})
print(r.url)   # ...get.php?key1=value1&key2=value2&key2=value3
r = requests.post(url, data={'name': '백도', 'age': 12})   # 인코딩을 알아서 해 준다
```

확인한 점:

- `requests.request('get', url)`과 `requests.get(url)`은 같은 요청이다.
- HEAD 요청은 헤더만 받고 본문은 받지 않아서 `r.text`가 비어 있었다.
- `r.content`는 바이트, `r.text`는 `requests`가 인코딩을 추측해서 바꾼 문자열이다.
- `exam.html`은 응답 헤더가 `Content-Type: text/html`로 charset이 없었다. 이럴 때 `requests`는 기본값(ISO-8859-1)으로 풀어서 한글이 깨질 수 있어서 `r.encoding = 'utf-8'`로 직접 지정했다.
- 이미지는 `r.content`를 `BytesIO`로 감싸 `PIL.Image`로 열고 `save()`로 저장했다. `urllib.request.urlretrieve(url, 파일명)`을 쓰면 한 줄로 저장된다.

## 3. BeautifulSoup으로 골라내기

```python
bs = BeautifulSoup(html, 'html.parser')
bs.find('p')                          # 첫 번째 <p> 하나 (Tag)
bs.find_all('p')                      # 모든 <p> (ResultSet, 리스트처럼 사용)
bs.find('p', class_="myp")            # class는 예약어라 class_
bs.find('p', attrs={"align": "left"})
bs.find('p').get_text(strip=True)     # 태그 안 글자, 앞뒤 공백 제거
bs.find('p').get("align")             # 속성 값
bs.select('#f_subtitle')              # CSS 선택자, 결과는 항상 리스트
bs.select('aside > h2')
```

- `.text`, `.string`, `get_text()`는 모두 태그 안의 글자를 꺼내는데 앞뒤 공백까지 그대로 나온다(`| text contents |`). `strip()`이나 `get_text(strip=True)`로 지운다.
- 실습 페이지(`exercise_css.html`)에서 `select()`로 찾은 결과: `h1` 1개, id `f_subtitle` 1개, class `subtitle` 2개, `aside > h2` 1개, `src` 속성이 있는 태그 1개.

## 4. YES24 파이썬 책 수집

YES24 검색 결과에서 책 제목은 `a.gd_name` 태그에 있다.

```python
r = requests.get('https://www.yes24.com/Product/Search', params={'domain': 'BOOK', 'query': 'python'})
bs = BeautifulSoup(r.text, 'html.parser')
for dom in bs.select('a.gd_name'):
    title.append(dom.string)
    link.append(dom["href"])        # '/product/goods/119293186' 같은 상대 경로
```

| 실습 | 결과 | 저장 방식 |
|---|---|---|
| 1페이지 | 24권 | 문자열로 직접 `title + "," + link` 작성 → `booklink_1page.csv` |
| 1~10페이지 (`&page=` 반복) | 240권 | pandas `DataFrame.to_csv()` → `booklink_10page.csv` |

확인한 점:

- **CSV를 직접 쓸 때 쉼표 문제**: 1페이지 결과는 제목에 쉼표가 없어서 24행 × 2열로 잘 저장됐다. 하지만 2페이지의 "문제 해결의 언어, 파이선 Python" 같은 제목이 들어가면 열이 하나 더 생겨 깨진다. pandas `to_csv()`는 이런 값을 따옴표로 감싸 주므로 안전하다.
- **`to_csv()`의 인덱스 열**: 기본으로 인덱스까지 저장해서 다시 읽으면 `Unnamed: 0` 열이 생긴다. 필요 없으면 `index=False`.
- 링크는 상대 경로라서 실제로 쓰려면 `https://www.yes24.com`을 앞에 붙여야 한다.
- 같은 책("Python으로 시작하는 빅데이터분석 및 인공지능")이 1페이지와 2페이지에 한 번씩 나와 240권 중 중복이 1건 있었다.

## 5. 바이브 코딩: 같은 일을 AI에게 시키기

Gemini와 ChatGPT에 같은 프롬프트를 보냈다.

```txt
https://www.yes24.com/Product/Search?domain=BOOK&query=python&page=1 부터
https://www.yes24.com/Product/Search?domain=BOOK&query=python&page=10 까지
각 페이지마다 출력되는 파이썬 관련 서적의
제목과 이 제목에 설정된 링크의 URL 문자열을 추출해서 각각
리스트에 저장하여 출력하는 파이썬 코드를 작성해줘
```

| | 직접 짠 코드 | Gemini | ChatGPT |
|---|---|---|---|
| 찾는 방법 | `select('a.gd_name')` | `select('a.gd_name')` | `select('div.itemUnit')`로 책 단위를 찾고 그 안에서 `select_one('a.gd_name')` |
| 제목 | `.string` | `get_text().strip()` | `.text.strip()` |
| 링크 | 상대 경로 | `https://www.yes24.com` + 상대 경로 | `https://www.yes24.com` + 상대 경로 |
| 그 밖에 | | `User-Agent` 헤더, `try/except`, 페이지마다 `time.sleep(0.5)` | `User-Agent` 헤더 |
| 결과 | 240권 | 240권 | 240권 |

- 셋 다 결과는 240권으로 같았지만 코드 구조는 달랐다. AI 코드는 절대 URL 만들기, 요청 헤더, 서버 부담 줄이기(`sleep`) 같은 실무 처리가 더 들어 있었다.
- Gemini 코드는 `headers`를 두 번 정의해서 첫 번째 값이 바로 덮어써진다. 동작에는 문제가 없지만 AI 코드도 읽어 보고 다듬어야 한다.
- 결과 개수(240)를 직접 확인해 보는 것이 AI 코드를 믿기 전에 할 일이었다.

## 6. 강의 교안 정리: 웹 데이터 수집의 기본

**정적 수집과 동적 수집**

웹 데이터 수집은 페이지를 받아오는 **크롤링**과, 받은 내용에서 원하는 부분을 뽑는 **스크래핑**으로 나뉜다.

| | 정적 수집 | 동적 수집 |
|---|---|---|
| 라이브러리 | `urllib`, `requests` | `selenium` |
| 대상 | 정적 웹 페이지 | 정적 + 동적 웹 페이지 |
| 속도 | 빠름 (페이지 조작이 필요 없음) | 상대적으로 느림 |

**urllib 패키지의 모듈**: 파이썬 표준 라이브러리라 설치 없이 쓴다.

| 모듈 | 역할 |
|---|---|
| `urllib.request` | URL로 요청 (`urlopen()`, `Request`, `urlretrieve()`) |
| `urllib.parse` | URL 해석과 인코딩 (`urlparse()`, `urlencode()`, `quote_plus()`) |
| `urllib.error` | 요청 중 생기는 예외 (`HTTPError` 등) |
| `urllib.response` | 응답 관련 클래스 |
| `urllib.robotparser` | 사이트의 `robots.txt`(수집 허용 규칙) 해석 |

- `urlopen()`의 결과(`HTTPResponse`)에서 `read()`(본문, 바이트), `status`, `reason`, `getheader(이름)`, `getheaders()`를 쓴다.
- **인코딩 확인**: HTML의 `<meta charset>`을 보거나, 코드로 `urlopen(url).info().get_content_charset()`을 호출하면 응답 헤더의 문자 셋을 알려 준다.
- `urlparse("https://...?movieId=93252")`는 주소를 `scheme`, `netloc`, `path`, `query` 등으로 나눠 준다.

**requests**: 요청 방식(GET, POST, HEAD, PUT, PATCH, DELETE)마다 함수가 있고, `params=`(쿼리 문자열), `data=`(폼 본문), `json=`(JSON 본문), `auth=`(인증)를 딕셔너리로 넘긴다. urllib처럼 미리 인코딩하지 않아도 된다. 응답의 `text`는 헤더에 문자 셋이 없으면 ISO-8859-1로 풀기 때문에 한글이 깨질 수 있어서 `r.encoding = 'utf-8'`을 먼저 지정한다(2절 실습에서 확인).

**BeautifulSoup**

- 파서: `html.parser`(내장), `lxml`, `xml`/`lxml-xml`(XML), `html5lib` 중에서 고른다. XML API 응답에는 `"xml"` 파서를 썼다(lxml 설치 필요).
- 점(.)으로 태그 접근: `bs.h1`, `bs.html.body.h1`처럼 계층을 따라가거나 바로 태그명을 쓴다. `.name`(태그명), `['속성']`, `.attrs`, `.parent`, `.children`, `.next_sibling`, `.descendants`로 주변 태그로 이동한다.
- `find_all()`은 태그명뿐 아니라 태그명 리스트(`['p', 'img']`), 정규식(`re.compile('^b')`), 속성 조건(`id='link2'`, `src=re.compile('png$')`), 글자(`text=...`), 개수 제한(`limit=2`), 바로 아래 자식만(`recursive=False`)으로도 찾는다. `find()`는 `find_all(..., limit=1)`과 같고 없으면 `None`.
- `select()`의 CSS 선택자: `태그.클래스`, `#아이디`, `부모 > 자식`, `조상 자손`, `[속성]`, `[속성=값]`, `[속성^=시작]`, `[속성$=끝]`, `:nth-of-type(3)`.

**NumPy와 Pandas**: 교안 끝부분에서 소개했다. NumPy는 다차원 배열·행렬 계산을 빠르게 하는 과학 계산 라이브러리이고, Pandas는 행과 열로 된 표(DataFrame)로 데이터를 다루는 분석 라이브러리다. 이번 실습에서는 수집 결과를 `DataFrame`으로 만들어 `to_csv()`로 저장하는 데 썼다.

## 정리

| 하고 싶은 것 | 코드 |
|---|---|
| 페이지 받기 | `urllib.request.urlopen(url)` / `requests.get(url)` |
| 바이트 → 문자열 | `res.read().decode('utf-8')` / `r.text` (필요하면 `r.encoding = 'utf-8'`) |
| 파라미터 붙이기 | `urllib.parse.urlencode(dict)` / `requests.get(url, params=dict)` |
| POST | `urlopen(url, data=바이트)` / `requests.post(url, data=dict)` |
| 태그 찾기 | `find()`, `find_all()`, `select()`(CSS 선택자) |
| 글자, 속성 꺼내기 | `get_text(strip=True)`, `tag["href"]`, `tag.get("align")` |
| 저장 | `pd.DataFrame(...).to_csv(파일, index=False)` |

> 실습에서 만든 결과 파일(CSV, 이미지)은 다른 사이트의 자료를 수집한 것이라 저장소에 올리지 않았다.

</details>

## 2. DataFrame과 Series 기본

`DataFrame`은 엑셀 시트처럼 행과 열이 있는 2차원 표, `Series`는 컬럼 하나에 해당하는 1차원 자료구조다.

```python
# 딕셔너리의 key -> 컬럼명, value(리스트) -> 그 컬럼의 값들
mydataset = {
  'cars': ["BMW", "Volvo", "Ford"],
  'passings': [3, 7, 2]
}
myvar = pd.DataFrame(mydataset)
print(myvar)
```

```python
a = [1, 7, 2]
myvar1 = pd.Series(a)   # 인덱스를 지정하지 않으면 0, 1, 2, ... 자동 부여
print(myvar1)
print(myvar1[1])        # 정수 인덱스로 위치 조회
```

`index`를 직접 지정하면 숫자 대신 이름(라벨)으로 값을 조회할 수 있다.

```python
myvar2 = pd.Series(a, index=["x", "y", "z"])
print(myvar2["y"])
```

딕셔너리를 `Series`에 넘기면 key가 그대로 인덱스(라벨)가 된다.

```python
calories = {"day1": 420, "day2": 380, "day3": 390}
myvar3 = pd.Series(calories)
print(myvar3)
```

## 6. 컬럼 선택: Series vs DataFrame

컬럼 하나만 선택하면 `Series`, 컬럼명을 리스트로 감싸서 선택하면 `DataFrame`이 된다.

```python
ages = titanic["Age"]              # Series, shape: (행 개수,)
type(titanic["Age"])               # pandas.core.series.Series

age_sex = titanic[["Age", "Sex"]]  # DataFrame, shape: (행 개수, 2)
type(titanic[["Age", "Sex"]])      # pandas.core.frame.DataFrame
```

## 7. 조건으로 행 필터링하기

`titanic["Age"] > 35`처럼 조건식을 대괄호 안에 넣으면, SQL의 `WHERE`처럼 조건을 만족하는 행만 걸러낼 수 있다.

```python
above_35 = titanic[titanic["Age"] > 35]
above_35.shape
```

조건식 자체는 각 행이 조건을 만족하는지(True/False)를 담은 **불리언 Series**이고, 이걸 다시 대괄호에 넣는 것이 필터링의 원리다.

여러 조건은 `|`(OR), `&`(AND)로 결합할 수 있다. 각 조건은 반드시 괄호로 감싸야 한다(연산자 우선순위 때문).

```python
class_23 = titanic[(titanic["Pclass"] == 2) | (titanic["Pclass"] == 3)]
class_23.head()
```

## 8. loc / iloc로 행·열 동시에 선택하기

- `.loc[행조건, 열이름]` : **라벨(이름) 기준**으로 선택

```python
adult_names = titanic.loc[titanic["Age"] > 35, "Name"]
adult_names.head()
```

- `.iloc[행범위, 열범위]` : **정수 위치(순서) 기준**으로 선택 (슬라이싱이라 끝 인덱스는 미포함)

```python
titanic.iloc[9:25, 2:5]  # 10~25번째 행, 3~5번째 열
```

## 정리

| 문법 | 반환 타입 | 기준 |
|---|---|---|
| `df["컬럼"]` | Series | 컬럼명 하나 |
| `df[["컬럼1", "컬럼2"]]` | DataFrame | 컬럼명 리스트 |
| `df[조건식]` | DataFrame | 불리언 Series(조건) |
| `df.loc[행조건, 열이름]` | Series/DataFrame | 라벨(이름) |
| `df.iloc[행범위, 열범위]` | Series/DataFrame | 정수 위치(순서) |
